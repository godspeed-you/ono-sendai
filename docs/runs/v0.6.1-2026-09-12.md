## What went wrong, and what it cost

- **`language.yaml` does not transcode to JSON** (a non-string key); completion reads it lazily
  as YAML instead. One rebuild.
- **`[` read as the token being typed** inside `in [`: found by the first run of the completion
  tests. One fix.
- **Three acceptance assertions** named text the prompt paints in several colours, or
  `bare function: 3` where `to json` prints `[3]`. Found by the local `stabilization` run.
- **A cache-sharing test race** (CI run 1): two budget tests shared the process-wide provider
  cache; the two PTY tests added to the same file shifted the schedule. The cache-filling test
  moved into a binary of its own.
- **A real regression from #132** (CI run 1, case 100): the cursor question before the first
  prompt cost two seconds of startup at a terminal that never answers. ADR-0861 moved it to the
  prompts after a command. The local gate cannot see it (it runs no acceptance), and the local
  acceptance run that would have seen it was stopped in favour of CI.
- **That fix moved the wait into two PTY harnesses** (CI run 2, then the local gate): they give a
  prompt 400 ms or 800 ms and never answer the question. No placement of the wait suits both
  them and case 100, and crossterm's bound is fixed, so the harnesses answer as a terminal does.
  `timeline_view.rs` never ran in CI because the gate's `cargo test` stops at the first red
  binary; the whole package was then run with `--no-fail-fast` before the next push.
