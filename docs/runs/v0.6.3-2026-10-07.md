## What integration and review found

- **Integration defects, each fixed test-first by the orchestrator:** a zero budget refusing plain
  `measure` (49ec3b34); `to jsonl` undeclared in `to`'s contract, found by #149's new conformance
  suite on its first run (22863575); the first correction of that making every `stream<string>`
  producer end the object stream, which hung `tail file … --follow | sort` (65ed3e66); a stale
  explain assertion on `to`'s declared output (c4813fbc); a merge resolution
  that dropped the explain package's record-reading tests (1d81e904); acceptance cases 200 and 262
  reading refusals and records by position; case groups not covering the new cases.
- **Independent review** (two read-only Opus reviewers over the whole diff): four release-blocking
  defects — `explain` could run code through a prefix assignment, a glob match or a variable; a
  background job's `cd` moved the shell; a function ending in `each` piped into a mutation
  deadlocked; Ctrl-Z on a fed program left no prompt — and fourteen smaller ones. All fixed with
  tests that failed first; two findings refuted with evidence.

## Environment

- The host journal is 4 GB, which kept the baseline gate red until #280's shim.
- Disk: started at 72 GB free after deleting `target/debug/incremental`; fell to 13 GB at the busiest
  point with two `target/` directories building. Recovered by removing superseded test-binary hash
  variants, incremental caches of idle trees, stale scratch and the old release build. Removing a
  hash variant while a test run was in flight made one test binary vanish mid-run (re-run green) —
  pruning happens only between runs.
- The container was restarted once mid-run; the gate and one agent were lost and restarted, nothing
  committed was lost.
- `change_gates.rs` plans against the host's live services and fails while docker units come and go
  (recorded in `docs/STATE.md`).
