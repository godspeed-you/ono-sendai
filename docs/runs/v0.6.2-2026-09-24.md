## Defects found during the run (beyond the milestone's own)

- `kuang-sign pack` wrote holey files as GNU sparse entries the host refused (fixed).
- Compiled components carried the build host's CPU features, so an image built on one runner
  failed on another (fixed, ADR-0914).
- In the independent review: a path-based trust check with a check-to-map window before the one
  `unsafe` load, and artifacts surviving a wasmtime patch release (fixed, ADR-0915, ADR-0916); the
  size budget not enforced where packages are built (fixed, ADR-0866); verdict rules that could
  pass or skip a real regression in case 152 and the Profile L test (fixed, ADR-0883, ADR-0884);
  a few dozen smaller gaps in the harness, the release scripts and the core build.
- A key typed with a terminal resize was stranded by crossterm's edge-triggered reader (fixed,
  ADR-0920).
- A redirected resolution drawing cut paths inside the file name (fixed).
- Debug `kuang-compile` needed 38 CPU-seconds per component (fixed, ADR-0927).
- Recorded, not fixed (outside the milestone; `docs/STATE.md`): `help | head` broken-pipe panic,
  zero-tolerance `perf --compare`, case 077's one missed early answer, `trace interface`'s inode
  order, and others listed there.

Coordinator mistakes, caught before they were pushed: during the second integration round a
chained command committed an unclosed delimiter, and later conflict markers, into cherry-picked
commits; both were repaired and folded into the commits that introduced them before any push,
and every later pick ran one command at a time with a compile check.
